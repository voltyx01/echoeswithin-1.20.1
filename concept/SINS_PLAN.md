# План: прогрессия «Семь» (грехи, карты, древо, мануалы) v2

> Цель: прокачка, которая трогает **весь** спектр механик сборки (стамина, кувырок, пульс, Зов Улья, кукла, кровь, обыск, TACZ, ближний бой, LSO, медицина, еда, сон, скрытность, техника), не выглядит как «+5% к урону» и не ломает тон (всё через тело и психику).
> Этот файл — план работ. Контент (таблицы карт и скиллов) пойдёт в `SINS_DESIGN.md` v2 по шагу 4.

## 2. Спектр статов (инвентарь хуков)

Всё, что прокачка может трогать. **[есть]** — значение уже есть в нашем коде или в API мода, нужно только читать множитель. **[хук]** — нужен событийный хук или миксин. **[нет]** — механики нет, придётся делать или отказаться.

### 2.1 Тело (свой код)
| Стат | Источник | Статус |
|---|---|---|
| Макс. стамина, реген (интервал, задержка), расход на спринт / прыжок / удар | `stamina/` (`efw-stamina.toml`: maxStamina, regenInterval*, sprintDrainInterval, jumpCost, attackExtraStamina) | есть |
| Эффекты низкой стамины (замедление, слабость) | то же | есть |
| **Кувырок**: цена, дальность (`speed`), неуязвимость (resistanceLevel/Duration), кулдаун, слабость после, кувырок в жидкости | `stamina/StaminaEvents`, `roll/` | есть |
| **Пульс**: прирост от источников (твари в поле зрения, темнота, закрытые комнаты, урон, стрельба, прицел, спринт), скорость остывания, порог тремора / увода прицела / шлейфа (`bodyThreshold`), привыкание | `heartbeat/` | есть |

## 3. Архитектура

```
SinData (сервер, сохраняется, синхронизируется)
 ├─ грех, страницы, карты {id, ранг}, скиллы[13], очки, мануалы[5]
 └─ → SinStats.rebuild(player)
SinStats — «что сейчас у игрока»
 ├─ постоянные: Map<Stat, (add, mult)> + ванильные/LSO AttributeModifier
 └─ условные: список правил {условие, эффект, триггер, окно, кулдаун}
Системы спрашивают: SinStats.mult(player, Stat.ROLL_COST) — одна строка в каждом месте
```

1. **`Stat` — единый реестр id** (`stamina.max`, `roll.cost`, `roll.iframes`, `pulse.gain.parasite`, `pulse.decay`, `coth.stage_speed`, `doll.ready_blood`, `gun.recoil`, `gun.reload`, `melee.damage`, `loot.time`, `food.exhaustion`, `heal.power`, `stealth.visibility`, …). Каждая система из §2 читает свой множитель в одном месте.
2. **Атрибуты** (HP, скорость, LSO-сопротивления, reach) вешаются как `AttributeModifier` с UUID от id карты или скилла. Снимаются при пересборке.
3. **Условия** (переиспользуемые, задаются в json): HP < X, пульс > или < X, стамина < X, сытость ≥ X, жажда, влажность, температура (COLD…HOT), стадия Улья, кровь на теле ≥ X, кукла в инвентаре, присед, спринт, прицел, в руке (пистолет / винтовка / дробовик / ближнее / пусто), патронов в магазине ≤ X, темнота, ночь, под крышей, союзник ≤ R, «нет урона N с».
4. **Триггеры с окном** «после X → на N секунд»: кувырок, убийство (огнестрел / ближнее / хедшот), получение урона, перезарядка, конец обыска, еда / питьё, стим, сон, вид твари, приступ рвоты, активация куклы.
5. **Данные в json:** `config/efw/sins/<sin>.json` (черта, карты, скиллы), `config/efw/sins/common.json` (общие карты, «Благодать», корни), `config/efw/manuals.json`. Тексты RU/EN там же или в lang. Перезагрузка командой без перезапуска.
6. **Отладка:** `/efw seven give_page|points|reset|stats` и оверлей активных эффектов. Без этого баланс не настроить.

## 4. Рамка контента

### 4.1 Подсистемы
| | Роль | Цена |
|---|---|---|
| **Черта греха** (при выборе) | сигнатура: одна механика, меняющая стиль игры | одна поведенческая цена |
| **Карты** (страница = выбор 1 из 3) | кто ты и чем платишь | да, бафф + цена (П / Пс приоритетнее статов) |
| **Древо** | мощь и билд | нет |
| **Мануалы** | знание и мастерство, одинаковые для всех | нет |

### 4.2 Древо — геометрия как в UI
- **Корень** — сигнатура греха, открыт сразу (уже так в коде).
- **3 ветки × 4 ступени.** Вершины — три символа:
  - **Солнце** — тело: стамина, кувырок, движение, температура, сон;
  - **Матка** — кровь, пульс, забота: медицина, еда, кукла, Улей, союзники;
  - **Коса** — убийство: огнестрел, ближний бой, хедшоты, добивание.
- Ступени 1–3 — «условие → эффект», меняющее поведение. 4-я ступень (символ) — механика-вершина.
- Темы веток одни у всех грехов, наполнение у каждого своё. Так экран один, а 7 грехов играются по-разному.
- **Очки:** 12 очков + бесплатный корень = все 13. **Цветок сгорает целиком только к концу игры** (20 страниц, очко с 9-й по 20-ю или по квестам). Билд — это порядок и путь: что открыть сейчас, а что, когда будет поздно.

### 4.3 Матрица покрытия (обязательное правило)
Каждое семейство статов из §2 используют **минимум 2 греха**, у каждого греха — **минимум 5 семейств**. Черновая привязка:

| Семейство | Гнев | Гордыня | Жадность | Зависть | Влечение | Чревоугодие | Лень |
|---|---|---|---|---|---|---|---|
| Стамина / кувырок | ● | | | ● | ● | | ● |
| Пульс | ● | ● | | | ● | ● | ● |
| Зов Улья | | ● | | | | ● | |
| Кукла / кровь | ● | | | | ● | | |
| TACZ стрельба | | ● | ● | ● | ● | | ● |
| Ближний бой | ● | | | ● | | ● | |
| Хедшоты / добивание | ● | ● | | ● | | | |
| Обыск / разбор / патроны | | | ● | ● | | | |
| Температура / LSO тело | | | | | ● | ● | ● |
| Еда / жажда | | | ● | | | ● | |
| Медицина / стимы | | | | ● | ● | ● | |
| Скрытность | | | ● | | | | ● |
| Сон / отдых | | | | | | | ● |
| Техника / батареи / бодикам | | | ● | ● | | | |
| Износ | ● | | | | | | ● |

Сигнатуры (черновик, в один штрих):
- **Гнев** — кровь — топливо: кровь на теле копится быстрее, кукла заряжается от ближнего боя; цена: пульс остывает медленно.
- **Гордыня** — «не попасться»: пока HP выше 70%, точность растёт; первое попадание по тебе сбрасывает бонус.
- **Жадность** — нюх: контейнеры с ценным подсвечиваются, обыск быстрее; цена: бросить недообысканное нельзя без реплики и всплеска пульса.
- **Зависть** — «тот, кто сильнее»: бонусы против целей с HP выше твоего; в коопе — против целей союзника. **Соло-играбельна.**
- **Влечение** — пульс — топливо: высокий пульс даёт скорость и перезарядку; стимы дольше; цена: тяжёлый «отходняк».
- **Чревоугодие** — желудок: еда лечит и снимает страх, рвота от Улья реже; цена: голод быстрее.
- **Лень** — тишина: присед и неподвижность режут видимость, отдых сильнее; цена: медленный старт после покоя.

### 4.4 Правила контента
1. Никакой магии: любой эффект объясним телом (адреналин, мышцы, привычка, желудок, сон).
2. Никаких голых «+X%» на ступенях 2–4 и в сигнатурах. Только условие или триггер.
3. Карта: цена ≤ 60% ценности баффа. Ранги I–III (бафф ×1 / 1.6 / 2.2, цена ×1 / 1.4 / 1.8). Каждая 5-я страница — «Благодать» без цены.
4. Уникальные имена: карта и скилл не называются одинаково.
5. Реплики о цене — только с кулдауном (через `speech/`).
6. Ни один грех не держится на союзнике. Коопные бонусы — надбавка, а не основа.
7. Опираемся только на [есть] и [хук] из §2. **[нет]** не используем, пока механика не сделана.
