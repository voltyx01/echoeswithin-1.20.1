# Echoes Within — «Семь»: грехи, карты, древо, мануалы (v2)

> Дополнение к `ECHOES_WITHIN.md`. План и архитектура — `SINS_PLAN.md`.
> **Источник правды — json** (`src/main/resources/efw_sins/` в моде, копия в игре: `config/efw/sins/`). Этот файл сгенерирован из них; числа — стартовые для плейтеста.

## 1. Как устроено

| Подсистема | Роль | Цена |
|---|---|---|
| **Корень древа** (сигнатура греха) | одна механика, задающая стиль; открыт сразу | одна поведенческая цена |
| **Карты** (страница Откровения = выбор 1 из 3) | кто ты и чем платишь | бафф + цена |
| **Древо «Тайная вечеря»** (3 ветки × 4) | мощь и билд | нет |
| **Мануалы** (5 веток × 5 томов) | знание, одинаково для всех | нет |

- Страниц на мир: **20**. Очко древа на страницах 1, 3, 5, 7, 9, 11, 13, 15, 17, 18, 19, 20 → **12 очков + корень = 13**: цветок сгорает целиком только к концу. Сброса нет.
- Страница: 2 карты греха + общая. Страницы 5, 10, 15, 20 — три карты «Благодати» без цены.
- Повтор карты повышает ранг (до 3): бафф ×1.0 / ×1.6 / ×2.2, цена ×1.0 / ×1.4 / ×1.8.
- Ветки: **Солнце** — тело (стамина, кувырок, движение, температура, сон); **Матка** — кровь, пульс, забота (медицина, еда, кукла, Улей); **Коса** — убийство (огнестрел, ближний бой, хедшоты).
- Тестирование (op 2): `/seven pages N`, `/seven points N`, `/seven card <id>`, `/seven fire <trigger>`, `/seven stats`, `/seven reset`, `/seven reload`.
