# EFW Mod

Minecraft Forge 1.20.1 Mod
Author: **voltyx**, **neko**

## Features:
- Custom TACZ Hitmarker color logic:
  - **Red hitmarker** upon killing a target.
  - **White hitmarker** on all regular hits.

## Building:
Run `./gradlew build` in this directory.
The compiled jar will be in `build/libs/efw-1.0.0.jar`.

### Dependencies in `libs/`
These jars are not in the repository (they are other authors' mods). Put them into `libs/` before building:
- `tacz-1.20.1-1.1.8-hotfix2.jar`
- `ShoulderSurfing-Forge-1.20.1-5.2.0.jar`
- `geckolib-forge-1.20.1-4.8.4.jar`
- `locks_reforged-1.7.5.jar`
- `lostcities-1.20-7.5.7.jar`
- `player-animation-lib-forge-1.0.2-rc1+1.20.jar`
- `sodiumdynamiclights-forge-1.0.10-1.20.1.jar`
